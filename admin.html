Gambar, ZIP semua ukuran, preview semua tombol, Paket Lynk, rekam video, caption.

Gerakan cepat

  • Ketuk elemen di pratinjau untuk memilihnya · seret = geser · cubit = zoom & putar · ketuk 2× pada teks = ubah isi
  • ⛶ di atas = layar penuh editor · ← = kembali ke admin

Slider

  • Geser bulatannya; menyentuh jalur tidak mengubah apa-apa, jadi aman saat menggulir
  • Saat menggeser, tarik jari ke atas / bawah = gerak makin halus
  • − / + = satu langkah (tahan untuk mengulang) · ketuk angka = ketik nilai · ketuk 2× bulatan = kembali ke nilai awal
